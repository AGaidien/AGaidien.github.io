## Reflection

For a university assignment I had to create a portfolio in Github using markdown syntax the porfolio had to consist of my CV and mock interview recording.

The task I had to complete are as follows:
 * Create a Github repository and set up pages
 * Create a CV in Github
 * Insert my mock interview into Github

Once I started the first step I took was to read through my subject guide to get a better understanding on how the assignment should be completed, after I read the guide
I created a Github repository, next I began on creating my CV using markdown syntax, I will admit it took me some time to understand how to use markdown but once i understood it was quite easy
after I had the basic information for my CV I started using better markdown to stylise and organise my CV. The next step was to add my mock interview this was very difficult at the time because
I was struggling to add my video to the repository after trouble shooting I realised I had to to set my repository to public which allowed me to add the video the second problem I faced was
trying to get my video to display I only realised later that the video does not display in the Github preview only on the actual website.

Once everything was completed I had a nicely designed portfolio that contained my CV and mock interview.
